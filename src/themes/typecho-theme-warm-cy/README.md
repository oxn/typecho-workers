# Typecho Warm CY

**主题版本：** 2026.11.13.10.49（北京时间）

基于 Typecho Warm 的独立自定义主题，适用于 Typecho-Workers。主题负责页面模板、文章排版、主题交互和视觉样式；Markdown 内容解析及其配套能力统一由 Markdown Rehype 插件负责。

## 主题职责

- 页面模板、文章排版与主题视觉样式。
- 文章目录的展示与阅读位置跟随。
- 页脚、导航及 CY 主题专属设置。
- 笔记媒体网格及附件展示。
- 本站上传图片的 URL 优化参数。

## Markdown Rehype 插件职责

推荐启用 `typecho-plugin-markdown-rehype`。Markdown 内容相关能力统一由插件实现和维护，包括：

- Markdown 解析与 HTML 转换。
- 数学公式、代码高亮及代码复制。
- Mermaid 流程图渲染。
- 图片布局、图片查看器及 BlurHash 占位。
- Markdown 内容运行时及对应样式。

CY 主题不再重复实现或加载上述 Markdown 功能，也不再单独依赖 Mermaid、KaTeX 或 MathJax。

## 注意事项

- 不修改 Typecho 核心文件。
- 文章 HTML 兼容不代表允许任意脚本执行；插件仍会对原始 HTML 做安全过滤。
- 主题的目录与插件自带目录不要同时开启，以免重复生成。

## 主题设置与媒体显示

主题元数据中的当前设置包括：

- **内容列表加载**：手动、滚动加载 2 次、无限滚动。
- **评论组件加载**：手动、停留 3 秒加载、自动加载。
- **评论列表加载**：手动、自动加载第一页、滚动加载 2 次、无限滚动。
- **图片优化参数**：分别为正文原图与缩略图追加安全过滤后的查询参数；只处理识别为本站上传目录的图片，不改写 GIF、SVG 或外站图片。
- **页脚与导航**：页脚链接、RSS、可选自定义页脚 HTML；笔记插件启用时主导航显示笔记入口。

笔记媒体由 `WarmNoteMedia.astro` 呈现：图片网格最多先显示 4 张，更多图片可展开并进入查看器；视频和音频使用原生控件；其他附件以文件链接呈现。附件分桶数据由 Notes 插件提供。
