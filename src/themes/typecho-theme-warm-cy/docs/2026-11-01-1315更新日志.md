# 2026-11-01 更新日志

## 一、Edge Cache 管理员身份同步优化

涉及文件：

- `src/plugins/typecho-plugin-cache/index.ts`
- `src/lib/plugin.ts`
- `src/layouts/Base.astro`
- `src/themes/typecho-theme-warm-cy/components/WarmShell.astro`
- `src/themes/typecho-theme-warm-cy/components/Post.astro`
- `src/themes/typecho-theme-warm-cy/components/Page.astro`
- `src/themes/typecho-theme-warm-cy/components/Index.astro`
- `src/themes/typecho-theme-warm-cy/components/NotFound.astro`

### 修改内容

1. 在 Edge Cache 插件中增加管理员身份检查 action，复用现有插件操作 API。
2. 增加管理员身份同步客户端脚本，仅在 Edge Cache 插件启用且管理员已登录时注入。
3. 监听浏览器重新获得焦点和 InstantClick 页面切换事件，按需检查管理员身份。
4. 身份一致时不刷新页面；身份不一致或登录状态失效时刷新页面，确保前台管理入口与真实登录状态一致。
5. 增加刷新保护，避免身份异常时反复刷新。
6. 将用户身份信息传递到主题布局及插件 Hook 上下文，支持服务端按登录状态渲染页面。

### 设计原则

- Edge Cache 插件启用状态是身份同步功能的唯一开关。
- 插件停用时不执行额外身份检查。
- 匿名访客不会收到身份同步脚本，也不会产生额外身份 API 请求。
- 沿用现有管理员认证和 CSRF 验证机制，不重写认证体系。
- 不修改 InstantClick 原始脚本，不改变原有页面缓存策略。
- 不增加定时轮询。

## 三、前台导航栏增加登录状态入口

涉及文件：

- `src/themes/typecho-theme-warm-cy/components/WarmShell.astro`
- `src/themes/typecho-theme-warm-cy/style.css`

### 修改内容

1. 在顶部导航栏最末尾增加登录状态入口。
2. 未登录时显示固定 SVG 登录图标，点击进入登录页面。
3. 已登录时显示用户昵称，优先使用 `screenName`，没有昵称时使用用户名。
4. 已登录时点击用户名进入个人资料页面。
5. 使用 `data-no-instant`，避免 InstantClick 接管登录和个人资料页面的跳转。
6. 复用现有 `user` 和 `isLoggedIn` 数据，不增加额外身份 API 请求。

### 新增 CSS

```css
.warm-nav__account {
  gap: 6px;
}

.warm-nav__account-icon {
  width: 16px;
  height: 16px;
  flex: 0 0 auto;
}
```

样式说明：

- 登录入口内部元素间距为 6px。
- SVG 图标宽高均为 16px。
- 使用 `flex: 0 0 auto` 防止图标被 Flex 布局压缩。
