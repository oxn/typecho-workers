# CoreDownload 插件

为文章编辑器增加独立的下载信息配置面板，配置写入文章现有的 `typecho_fields` 自定义字段，不新增数据库表，也不修改文章保存 API。

## 当前阶段

- 通过 `admin:writePost:bottom` 注入文章编辑器面板。
- 使用 `coreDownload` 字段保存 JSON。
- 支持下载区标题、顶部说明、多条下载链接（网盘名称、下载地址、提取码、备注）和底部说明。
- 编辑文章时从已有字段回填；提交时同步到现有自定义字段表单。
- OXN 主题文章详情页通过客户端脚本创建下载区 DOM；服务端仅输出空容器和必要配置数据。
- 普通下载地址只允许 HTTP/HTTPS；文章本身处于密码锁定状态时不查询、不输出下载配置。
- 当前前台 CSS 是用于本地验证功能的临时基础样式，不代表原版样式复刻。
- 下载链接口令目前作为提取码展示并支持复制；独立下载区口令验证/隐藏地址仍未实现。

## 字段格式

```json
{
  "version": 1,
  "title": "下载资源",
  "intro": "",
  "links": [
    {
      "name": "网盘名称",
      "url": "https://example.com/file",
      "password": "",
      "note": ""
    }
  ],
  "footer": ""
}
```

当前前台已接入客户端 DOM 渲染和提取码复制。独立下载区口令验证、原版 CSS/HTML 精确复刻仍属于后续阶段。当前数据结构不代表已经完整复刻原插件的全部字段或交互。
