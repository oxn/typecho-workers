# CoreDownload 插件

为文章编辑器增加独立的下载信息配置面板，配置写入文章现有的 `typecho_fields` 自定义字段，不新增数据库表，也不修改文章保存 API。

## 当前阶段

- 通过 `admin:writePost:bottom` 注入文章编辑器面板。
- 使用 `coreDownload` 字段保存 JSON。
- 支持下载区标题、顶部说明、多条下载链接（网盘名称、下载地址、提取码、备注）和底部说明。
- 编辑文章时从已有字段回填；提交时同步到现有自定义字段表单。
- 暂不包含前台渲染、口令保护和原版样式复刻。

## 字段格式

```json
{
  "version": 1,
  "title": "下载资源",
  "intro": "",
  "links": [
    {
      "name": "网盘名称",
      "url": "https://example.com/file",
      "password": "",
      "note": ""
    }
  ],
  "footer": ""
}
```

前台客户端渲染、链接保护和原版 CSS/HTML 的复刻属于后续阶段。当前结构是后台配置阶段的数据格式，不代表已经完整复刻原插件的字段或交互。
