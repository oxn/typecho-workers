## 2026.11.15 — Rin 文章渲染复刻进行中

### 已迁移
- Markdown 解析顺序调整为 Rin 使用的 GFM、Mermaid、数学公式、GitHub Alerts 和软换行。
- 数学公式固定走 KaTeX，移除 MathJax 及其配置、浏览器运行时和预览分支。
- Mermaid 使用亮色/暗色双份容器，并由 Markdown 插件按需加载运行时。
- 文章根节点统一为 `.toc-content`，不再依赖主题的 Markdown 内容样式类。
- 图片迁移 URL 元数据、行内/块级布局、BlurHash、加载与失败状态。
- 图片灯箱实现下载、缩放、计数、键盘与触摸导航。
- 代码块使用 Prism，提供亮色/暗色代码主题、长行换行和复制按钮。
- 文章组件样式覆盖标题、段落、链接、引用、列表、表格、脚注、上下标、GitHub Alerts 和 iframe。
- 前台和后台预览共用同一套 Markdown 输出与浏览器运行时。

### 清理
- 删除旧 MathJax、CJK、Emoji、ins、目录、灵活代码标题/容器、highlight.js、slug 和标题自动锚点等旧渲染分支。
- 移除渲染阶段对后台设置和主题专用运行时的依赖；现有设置界面保留，暂不生效。
- 图片、Prism 运行时改为按内容需要加载，避免无图片/代码文章下载对应运行时。

### 尚未验收
- 当前为静态代码迁移，未运行构建、测试或部署。
- 仍需在浏览器中与 Rin 原文逐项对照，完成验证后才能标记为交付版。
