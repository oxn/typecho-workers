# Markdown 显示增强

独立的前端显示增强插件，仅处理页面已经输出的文章和独立页面 DOM，不参与 Markdown 解析，不改写文章内容，不访问数据库，也不执行 D1/KV 读写。

## 功能

- 数学公式：KaTeX
- Mermaid 图表：流程图等图表
- 代码语法高亮：Highlight.js

三个功能均可在插件设置中独立启用或关闭。流程图增强会保留原始代码块，避免破坏主题已有的代码复制按钮。

## 页面与主题兼容

只在 post 和 page 页面注入资源。插件通过项目公共 archive:header / archive:footer 插件注入机制工作，不依赖 OXN 主题；主题需使用项目公共布局插件注入机制。

前端库通过 jsDelivr CDN 按启用项加载。首次访问相关页面时需要浏览器能够访问 jsDelivr。
