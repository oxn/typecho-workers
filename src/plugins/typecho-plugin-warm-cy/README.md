# CY 服务插件

CY 服务插件为 Warm CY 主题提供管理界面和前台管理交互。

## 保留功能

- 首页文章置顶与取消置顶
- 前台搜索入口和搜索框
- 评论区管理入口及管理员操作信息
- 后台 CY 服务设置页面和主题设置快捷入口
- 首页置顶文章 ID 管理
- 十组页脚链接配置
- 文章内容声明（免责声明）配置
- 站点底部自定义 HTML
- 主题后台设置项的界面整理

置顶和评论管理操作继续使用原有的权限校验、确认参数和安全令牌机制。搜索入口继续支持主题的局部页面切换。

## 内容渲染边界

本插件不参与文章或独立页面的正文渲染，也不注册正文内容处理钩子。

以下机制已从插件中移除：

- Markdown 内容处理
- Markdown Alert 图标恢复
- HTML 保护标记、恢复和增强
- HTML sanitizer
- CSS、SVG、Script runtime
- iframe HTML 恢复

文章与页面正文的 Markdown/HTML 渲染由主题及系统核心各自负责。CY 服务插件不会改写正文，也不会向正文注入恢复标记或运行时脚本。

## 不包含的请求处理功能

插件不再提供备用域名跳转等非界面请求处理功能。站点域名和内容安全策略仍由系统核心配置管理。

## 设置保存

插件设置通过后台保存。置顶列表、页脚链接、文章声明和站点底部自定义 HTML 仍保存在原有主题/插件选项中；保存时会清理旧版本遗留的正文增强和备用域名跳转开关。
