# CY 服务插件

**插件版本：** 2026.11.18.22.04（北京时间）

CY 服务插件是 Typecho Warm CY 主题的配套管理插件，提供后台设置入口、主题配置管理及少量前台管理交互。插件与主题分工独立：插件负责管理，主题负责前台页面和正文输出。

## 功能说明

- 首页文章置顶与取消置顶。
- 前台搜索入口和搜索框的配套设置。
- 评论区管理入口及管理员操作信息。
- 独立的 CY 服务插件后台设置页面。
- 主题设置页中的 CY 服务插件快捷入口。
- 首页置顶文章 ID 管理。
- 十组页脚链接配置。
- 文章内容声明（免责声明）配置。
- 站点底部自定义 HTML。
- 主题后台设置项的界面整理。
- 后台入口显示/隐藏设置。

置顶和评论管理操作继续使用原有的权限校验、确认参数和安全令牌机制。搜索入口继续支持主题的局部页面切换。

## 内容渲染边界

CY 服务插件不参与文章或独立页面的正文渲染，也不注册正文内容处理钩子。

以下正文处理机制不属于本插件：

- Markdown 内容解析与 DOM 渲染。
- Markdown Alert 图标及正文标记处理。
- HTML 增强与正文 HTML 处理。
- HTML sanitizer。
- CSS、SVG 及其他正文客户端 runtime。
- Mermaid、公式等正文渲染模块。

以上前台正文能力由 Warm CY 主题内置的统一 CY Client Runtime 和主题自有 Renderer 负责。主题使用 Unified / Remark / Rehype 生态及相应扩展库构建 Markdown 处理管线；具体依赖和职责见主题 README。前台不依赖 `typecho-plugin-markdown-rehype` 插件包，也无需为了主题正文输出启用该插件。

## 不包含的请求处理功能

插件不提供备用域名跳转等非界面请求处理功能。站点域名和内容安全策略仍由系统核心配置管理。

## 设置保存

插件设置通过后台保存。置顶列表、页脚链接、文章声明和站点底部自定义 HTML 继续保存在对应的主题/插件选项中；保存时会清理旧版本遗留的正文增强和备用域名跳转开关。
