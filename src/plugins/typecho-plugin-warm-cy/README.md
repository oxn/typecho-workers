# Warm CY 配套插件

为 `typecho-theme-warm-cy` 提供主题配套功能、后台设置和前台增强。插件 ID：`typecho-plugin-warm-cy`。

## 功能

- **主题配套管理**：提供置顶管理、评论区操作、首页搜索显示设置及 Warm CY 相关后台入口。
- **正文 HTML 增强**：允许文章和独立页面正文按需保留 HTML 的 `class`、`id`、`data-*`、`aria-*`、`style` 属性，以及内嵌 CSS、JavaScript 和 SVG。此功能默认关闭，可在插件设置中开启。
- **内容范围**：正文增强只处理文章和独立页面；notes 由独立笔记插件处理，评论区不受影响。
- **Markdown Alert 样式**：支持 NOTE、TIP、IMPORTANT、WARNING、CAUTION 五种提示框样式，可分别调整样式、图标显示、图标尺寸和间距。
- **主域名自动跳转**：可选将备用域名请求临时跳转到 D1 站点选项 `siteUrl` 指定的主域名，保留路径和查询参数；后台、API 和静态资源不参与跳转。功能默认关闭。
- **主题适配**：前台注入和 Alert 样式仅在当前主题为 Warm CY 时启用。

## 设置入口

在 Typecho 后台打开插件的 **CY 功能显示** 设置页（`/admin/plugin/cy-companion`）。

HTML 增强和主域名跳转均为独立开关，默认关闭。启用 HTML 增强后，文章/页面中作者提供的脚本会在访客浏览器执行，因此只应允许可信任的内容发布者使用。

## 版本

- 插件版本：`1.1.0`
- 构建版本：`2026.11.07.21.00`

插件版本独立于 Warm CY 主题版本；更新插件时无需修改主题核心文件。
