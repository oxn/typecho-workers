# 更新日志

## 2026.11.18.22.04（北京时间）

### 职责边界
- 明确 CY 服务插件只负责后台管理、主题配套设置及管理交互。
- 明确文章与独立页面的 Markdown/HTML 解析、正文 DOM 输出和客户端渲染均由 Warm CY 主题自有 CY Client Runtime 与 Renderer 负责。
- 补充主题使用 Unified / Remark / Rehype 生态构建 Markdown 处理管线的说明。
- 明确主题前台不依赖 `typecho-plugin-markdown-rehype`，无需启用该插件。

### 后台设置
- 主题设置页保留 CY 服务插件快捷入口，移除 Markdown Rehype 插件快捷入口。
- 保留首页置顶、搜索入口、评论管理、页脚链接、文章内容声明和站点底部自定义 HTML 等管理能力。

### 说明
- 本次更新记录同步当前插件功能和主题/插件职责划分。
- 文档记录不代表已完成本地构建、自动化测试或线上部署验证。
