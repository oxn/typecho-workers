# 拼音别名

在文章和独立页面编辑器中，根据标题自动建议 ASCII 拼音缩略名。

## 行为

- 只在对应永久链接格式包含 `{slug}` 时启用；不修改站点永久链接设置。
- 新建内容且别名为空时，根据标题自动生成建议。
- 编辑已有内容时不自动覆盖现有别名。
- 作者手动编辑别名后，自动建议停止；点击「重新生成拼音」才会主动覆盖。
- 生成失败不会阻止文章或页面保存。
- 标题转换由本站 Worker 完成，使用本地依赖 `pinyin-pro`，不加载第三方 CDN。
- API 仅接受 POST，并通过现有管理员权限、同源和 CSRF 校验。

## 范围

插件不修改核心编辑器、保存 API、数据库或主题文件。最终别名仍通过上游原有编辑表单保存，并由上游唯一性逻辑处理重名。

## 拼音分隔规则

- 连续汉字直接拼接拼音，例如“中华人民共和国”生成 `zhonghuarenmingongheguo`。
- 原标题中的空格、标点和符号转换为 `-`，连续分隔符合并为一个，首尾不保留 `-`。
- 已有别名不会因标题变化而自动替换；新建时手动填写的别名也会保留。
- 该规则只影响文章和独立页面的默认别名建议，不改变标签 slug 规则。
